## 💡 Featured Projects

### 🧠 1. Explainable Depression Detection from Social Media Text

**Tech Stack:** Python · DistilBERT · SHAP · React · FastAPI

- Fine-tuned a DistilBERT NLP model to analyze social media text.
- Achieved **95.5% classification accuracy** for early depression detection.
- Integrated SHAP to provide explainable model insights.
- Developed a full-stack application using React and FastAPI.

### 🔍 2. NLP-Driven GitHub Technology Trend Discovery

**Tech Stack:** Python · Scikit-learn · NLTK · Streamlit · GitHub REST API

- Collected and analyzed **5,000+ GitHub repositories** using the GitHub REST API.
- Applied TF-IDF and K-Means clustering to discover technology trends.
- Explored repository popularity through stars, keywords and similarity metrics.
- Developed an interactive Streamlit analytics dashboard.

### 🚀 3. CareerCompass AI

**Tech Stack:** Python · FastAPI · React · LangGraph · Tailwind CSS · NLP

- Designed a deterministic multi-agent AI system with **6 specialized agents**.
- Used LangGraph to orchestrate personalized career roadmap generation.
- Developed a React and FastAPI interface.
- Implemented real-time AI response streaming and skill-gap analysis.

### 🌿 4. FocusZen – AI-Assisted Student Productivity Platform

**Tech Stack:** Python · Laravel · PHP · JavaScript · MySQL · Flask

- Developed a full-stack student productivity platform.
- Implemented study time tracking, task scheduling and gamified achievements.
- Integrated Python Flask microservices for behavior-based recommendations.
- Developed personalized study content and sleep schedule recommendations.

### 🌊 5. Flood Risk Assessment & Vulnerability Mapping Dashboard

**Tech Stack:** Power BI · Data Analysis · Geospatial Visualization

- Analyzed flood vulnerability across **25 Sri Lankan districts**.
- Worked with 25,000 location records.
- Evaluated elevation, rainfall, drainage and river proximity.
- Built interactive visualizations to identify vulnerable locations and major risk drivers.

### ☁️ 6. AWS-Based Customer Churn Prediction & Analytics Solution

**Tech Stack:** AWS S3 · Lambda · CloudWatch · Glue · Athena · XGBoost

- Built an end-to-end cloud-based customer churn analytics pipeline.
- Implemented event-driven data validation and serverless SQL analytics.
- Developed churn prediction models using machine learning.
- Achieved **80.21% recall and 0.8468 ROC-AUC** using Focal Loss XGBoost.

### 📚 7. Online Course Analytics Dashboard

**Tech Stack:** Python · Streamlit · Selenium · Pandas · Matplotlib

- Scraped nearly **10,000 course records** from Udemy and Coursera.
- Collected and unified cross-platform course information.
- Developed an interactive Streamlit dashboard.
- Implemented search filters, platform comparisons and price-to-duration visualizations.
